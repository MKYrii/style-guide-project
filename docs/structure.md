# Шаблоны документов

## Типы документов

| Тип | Назначение | Аудитория |
|---|---|---|
| README | Быстрый старт и обзор проекта | Все |
| Руководство пользователя | Пошаговое решение задач | Конечные пользователи |
| Описание API | Справочник методов и параметров | Разработчики-интеграторы |
| Инструкция для разработчиков | Сборка, тестирование, релизы | Команда проекта |

## README

Обязательные разделы в таком порядке:

1. Название и одно предложение о том, что делает проект.
2. Требования к окружению.
3. Установка.
4. Быстрый старт с рабочим примером.
5. Ссылки на подробную документацию.
6. Как внести вклад и лицензия.

Пример каркаса:

````markdown
# Название проекта

Приложение для учёта задач в команде.

## Требования

Python 3.10 или новее.

## Установка

```bash
pip install taskboard
```

## Быстрый старт

```bash
taskboard init
```

## Документация

[Руководство пользователя](docs/user-guide.md)

## Как внести вклад

См. [CONTRIBUTING.md](CONTRIBUTING.md). Лицензия — MIT.
````

## Руководство пользователя

Каждая статья строится по схеме:

1. **Заголовок** — глагол в неопределённой форме: «Создать проект».
2. **Вводное предложение** — зачем это нужно и что получится.
3. **Предварительные условия** — списком.
4. **Шаги** — нумерованный список, одно действие в шаге.
5. **Результат** — как понять, что всё получилось.
6. **Возможные проблемы** — таблица «симптом — причина — решение».

Пример:

````markdown
## Создать проект

Проект объединяет задачи одной команды. После создания он появится в списке.

Предварительные условия:

- вы вошли в систему;
- у вас есть роль «Администратор».

1. Откройте **Проекты**.
2. Нажмите **Создать**.
3. Введите название и нажмите **Сохранить**.

Результат: проект появится в списке.

| Симптом | Причина | Решение |
|---|---|---|
| Кнопки **Создать** нет | Нет роли «Администратор» | Попросите администратора выдать роль |
````

## Описание метода API

Для каждого метода указывайте:

- HTTP-метод и путь;
- краткое описание в одном предложении;
- таблицу параметров (имя, тип, обязательность, описание);
- пример запроса и ответа;
- таблицу кодов ошибок.

Пример:

````markdown
## GET /api/v1/projects/{id}

Возвращает проект по идентификатору.

| Параметр | Тип | Обязателен | Описание |
|---|---|---|---|
| `id` | integer | Да | Идентификатор проекта |

Пример запроса:

```bash
curl https://example.com/api/v1/projects/42
```

Пример ответа:

```json
{ "id": 42, "name": "Docs" }
```

| Код | Описание |
|---|---|
| 200 | Проект найден |
| 404 | Проект не найден |
````

## Файлы и имена

- Имена файлов — строчные латинские буквы, слова через дефис: `quick-start.md`.
- Один файл — одна тема.
- Размер файла — до 500 строк. Больший файл разбейте на части.
