# Словарь и глоссарий

Один термин используется в одном значении и пишется одинаково во всех документах. Если термина нет в таблице, добавьте его через Pull Request.

| Термин | Определение | Не используем |
|---|---|---|
| Репозиторий | Хранилище кода и документации под управлением Git | репа, проект Git |
| Коммит | Зафиксированный набор изменений в истории Git | комит, сохранение |
| Ветка | Независимая линия разработки в репозитории | бранч |
| Pull Request | Запрос на слияние изменений из одной ветки в другую | пулл-реквест, ПР |
| Ревью | Проверка изменений другим участником | код-ревью (для документации) |
| Линтер | Инструмент автоматической проверки текста или кода по правилам | чекер |
| Сборка | Преобразование исходных файлов документации в готовый сайт | билд |
| Развёртывание | Публикация собранного сайта на сервере | деплой |
| Стайлгайд | Руководство по стилю | стиль-гайд |
| API | Интерфейс прикладного программирования | апи, АПИ |
| Эндпоинт | Адрес, по которому API принимает запросы | точка входа |

## Правила для новых терминов

1. Проверьте, нет ли уже подходящего термина.
2. Предпочитайте русское слово, если оно общепринято.
3. Если принят английский термин, пишите его в оригинале и добавьте пояснение при первом упоминании.
4. Укажите слова, которые использовать не нужно.
