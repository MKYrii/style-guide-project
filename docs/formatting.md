# Оформление текста

## Заголовки

- Один заголовок первого уровня на файл.
- Не пропускайте уровни: после `##` следует `###`, а не `####`.
- В конце заголовка не ставьте точку.
- Заголовок — не длиннее 60 символов.

## Списки

- Маркированный список — для равноправных элементов, нумерованный — для последовательных шагов.
- Все пункты списка начинаются одинаково: все с глагола или все с существительного.
- Не вкладывайте списки глубже двух уровней.

## Выделение

| Элемент | Оформление | Пример |
|---|---|---|
| Элементы интерфейса | **Полужирный** | Нажмите **Сохранить** |
| Имена файлов, команды, параметры | `Код` | Откройте `mkdocs.yml` |
| Первое употребление термина | *Курсив* | *линтер* |

Не используйте подчёркивание и ЗАГЛАВНЫЕ БУКВЫ для выделения.

## Блоки кода

Всегда указывайте язык:

````markdown
```bash
mkdocs serve
```
````

- В блок кода помещайте только то, что читатель может скопировать и выполнить.
- Для приглашения командной строки не используйте `$`.
- Длинные строки переносите так, чтобы пример не прокручивался по горизонтали.

## Таблицы

- Используйте таблицы для сравнения по нескольким признакам.
- Первая строка — заголовки.
- Не более 5 столбцов.

## Изображения

- Формат: PNG для снимков экрана, SVG для схем.
- Имя файла: `section-description.png`.
- Обязательно задавайте альтернативный текст.
- Не размещайте важную информацию только на изображении.

## Примечания

Для предупреждений используйте блоки admonition:

```markdown
!!! warning "Внимание"
    Операция необратима.
```

Типы: `note` — дополнение, `tip` — совет, `warning` — риск потери данных.
